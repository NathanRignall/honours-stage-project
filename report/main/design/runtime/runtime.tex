\section{Runtime}

There were several options for operating systems, hypervisors and techniques to implement the software infrastructure and hence management program on. Several were analysed for real-time performance while evaluating the process isolation capabilities. This was vital for ensuring new software updates could be tested in an isolated environment without affecting the system's performance.
